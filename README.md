# Shadow Engine v0.1

Локальный визуальный редактор + HTTP API для композитинга автобуса и асфальтовой сцены с настраиваемыми 2.5D-тенями.

## Запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000 — исходники из `assets/` подгружаются автоматически. API-документация: http://127.0.0.1:8000/docs.

## API

`POST /api/render` — multipart/form-data:

- `background` — изображение JPG/PNG/WebP (обязательно)
- `vehicle` — изображение PNG/WebP с прозрачностью (обязательно)
- `settings` — JSON-строка, необязательно
- `format` — `png`, `jpeg` или `webp` (по умолчанию png)

Пример:

```bash
curl -X POST http://127.0.0.1:8000/api/render -F "background=@assets/background.webp" -F "vehicle=@assets/bus.png" -F 'settings={"x":55,"y":165,"width":1170,"shadow_angle":145,"shadow_length":130}' -o output.png
```

`GET /api/defaults` возвращает значения параметров. Для интеграции можно вызывать API с сервера основного конструктора. Система координат — пиксели исходного фона. Колёсные координаты — относительные значения 0..1 от исходного PNG автобуса.

## Ограничения v0.1

- Тень **2.5D**, рассчитана из альфа-силуэта и не является физически корректной 3D-проекцией. Тестируйте на каждом ракурсе.
- Автоматическое определение солнца, геометрии и точек колёс пока отсутствует.
- Для лучшего качества укажите координаты колёс отдельно для каждого ракурса и сохраните настройки для каждого фона.
- Нет авторизации и долговременного хранилища: не публикуйте API напрямую в интернет.
- Максимальный размер входного файла 25 МБ, разрешение изображения до 12 мегапикселей.
- Цветокоррекция упрощённая. На исходных PNG возможны ореолы вокруг контура, которые требуют отдельной очистки альфа-маски.

## Структура

- `engine.py` — независимый Python-модуль обработки
- `app.py` — FastAPI-приложение
- `static/index.html` — браузерный редактор
- `assets/` — предоставленные примеры
- `tests/` — проверка движка и API

## Публикация в Render через GitHub

1. Создайте **приватный** репозиторий GitHub и загрузите в него файлы проекта (содержимое архива, не сам ZIP).
2. В Render выберите New > Blueprint и подключите репозиторий. Render обнаружит `render.yaml`.
3. Подтвердите создание веб-сервиса. После сборки Render покажет публичный URL вида `https://shadow-engine-demo-....onrender.com`.
4. Откройте URL для тестирования редактора. Документация API доступна по `/docs`.

**Безопасность:** это демонстрационный сервис без авторизации. URL доступен любому, кто его знает; не загружайте конфиденциальные изображения. Для промышленной публикации добавьте авторизацию, rate limiting и ограничения на количество запросов. Бесплатный тариф может засыпать при простое и запускаться с задержкой.
